# Privacy Policy — Verification


_Last updated: October 25, 2026_


This policy describes the data handled by **Verification**, a Discord bot that screens members when they join a server.


## Data stored


Verification keeps a small record per screened member:


- Discord user ID of the member who joined
- Server ID the member joined
- The date the member joined and the date the screening was completed
- Whether the member passed the screening


Verification never reads message text, never tracks online status or activities, and stores nothing beyond the fields above.


## Purpose


The record exists so the server can tell which members have passed the join screening and so the record can be removed the moment a member leaves. The member list is used only for this check.


## Retention


A record exists only while the member is in the server. It is deleted within 24 hours after the member leaves.


## Access


Only the bot operator can reach the database. Records are not shared, not sold, and not used for advertising.


## Deletion


Open an issue in this repository, or message the bot owner on Discord, to have your record removed. Requests are handled within 7 days.


## Updates


If this policy changes, the new version replaces this page at the same address.
